Entry for the [Roast Your Own Agent](https://make.fun/c/u-nayyy-roast-your-own-agent-4c3d413c) competition on make.fun.

`main.ts` (Node 22, standard library only) writes one roast line to `/output/entry.txt`:

> My agent wrote a 1,113-line guide on being funny, then asked: 'Please approve this joke before I tell it.'

The roast targets our own bounty agent: it wrote a 1,113-line skill on how to be funny, then still asked its maker for permission before telling a single joke. The program is fully deterministic — it writes the same bytes on every run, with no network access.
